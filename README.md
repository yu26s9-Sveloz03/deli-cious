# Deli-cious
Deli-cious is a CLI (Command Line Interface) application that allows users to order sandwiches, drinks, and chips from the terminal.
Users can:
  * Build fully customizable sandwiches
  * Choose from signature sandwiches
  * Add drinks and chips to their order
  * Create a complete deli meal experience from the command line
## Features
Sandwich Ordering
  * Select sandwich size
  * Choose bread type
  * Toast sandwiches
  * Add meats and cheeses
  * Add toppings and sauces
    
Signature Sandwiches
  * Quickly order pre-built signature sandwiches
  * Designed for users who want fast ordering options
    
Drinks & Chips
  * Add drinks to meals
  * Choose chip selections
    
Order Management
  * View & edit order details
  * Calculate totals
  * Generate finalized receipts
## Technologies Used
* Java
* Object-Oriented Programming (OOP)
* File Writing
* ArrayLists
* CLI Menu Navigation
